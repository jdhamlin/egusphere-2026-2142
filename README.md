# egusphere-2026-2142
*repo for data and scripts to generate figures for egusphere-2026-2142 manuscript*

# Contents
1. Regression_Metrics.m - MATLAB function characterizing linear and quadratic regressions
2. aps_soars_polar_plc_output_202402.xlsx - APS PLC results
  a. Size resolved efficiency and loss given as a percent, diameter is in units of µm
3. egusphere_2026_2142_figures.m - matlab figure script
4. ops_soars_polar_plc_output_202402.xlsx - OPS PLC results
  a. Size resolved efficiency and loss given as a percent, diameter is in units of µm
5. smps_soars_polar_plc_output_202402.xlsx - SMPS PLC results
  a. Size resolved efficiency and loss given as a percent, diameter is in units of µm
6. soars_polar_bubbles_final.mat - subsurface bubble data ("all_stats" matlab structure)
  a. SST binned results
7. soars_polar_final.mat - smps-aps data ("all_stats" matlab structure)
  a. SST binned results
8. soars_polar_sm_ops.mat - sm-ops data ("all_stats" matlab structure)
  a. SST binned results
9. soars_polar_smops_final.mat - sm-ops data ("all_stats" matlab structure)
  a. Full sm-ops data, not SST binned
10. soars_polar_smps_aps.mat - smps-aps data ("all_stats" matlab structure)
  a. Full smps-aps data, not SST binned
11. spider_soars_polar_plc_output_202402.xlsx - SM PLC results
  a. Size resolved efficiency and loss given as a percent, diameter is in units of µm
